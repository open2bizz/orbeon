# --- Note by Dennis Ochse (2019-05-01) ---
Please add the following parameter to your Odoo configuration file:

xmlrpc_port_orbeon = 8069

8069 is the default, you are using a different port for xml_rpc change the port number.


Orbeon Config File

version = Orbeon Forms 2024.1.202501010102 CE

Example:
$ cd /var/lib/tomcat10/webapps/orbeon/WEB-INF/resources/config
$ nano properties-local.xml

ADD VIEW MODE BUTTONS orbeon runner:

show buttons in view mode:
<property
    as="xs:string"
    name="oxf.fr.detail.buttons.view.*.*"
    value="back workflow-edit pdf"/>

REMOVE the EDIT MODE BUTTON. Show ONLY PDF:
<property
    as="xs:string"
    name="oxf.fr.detail.buttons.view.*.*"
    value="pdf"/>
